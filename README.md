# owendots

Slackware64-current workstation installer, desktop configuration and control
tools. New implementation in progress; no release or installable system is
claimed yet. The agreed design and validation checklist are in [SPEC.md](SPEC.md).

New code uses Unlicense. Any third-party configuration excerpts retain their
original notices. The previous owenslackinstall repository is a design reference;
its GPL code is not incorporated into this Unlicense implementation.
